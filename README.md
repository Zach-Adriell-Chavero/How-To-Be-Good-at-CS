# How-To-Be-Good-at-CS
This repository guides people on how to master their problem thinking skills and situational analysis involving coding and programming in Computer Science.

## Tips on Studying CS
Studying CS a unique process because of how heavily applied the nature of computer science is.

### Do a quick run through of the terms
Before doing application, review on all terms, features, syntax, or methods. You have to learn how they work and function before actually using them. This is the period for memorizing key concepts.

### Analyze example codes
Analyze how these work in practice. If you're learning how `def` works, see a simple example code of its application. Example code:
```
def add(a, b):
   return a + b

add(1, 2)
```
Learn where they appear, how to use them, their applications, and specific uses.

### Do the work yourself
After preparing, now you can challenge yourself to do it.

Start by coding simple, like recreating the example code you were given. Strip it to the bare minimum so you get the feel of applying what you learned.

Slowly scale the difficulty of your exercises. Add more arguments, features, and overall add more complexity to your work. Do it one by one, and make sure you understand the process you are doing.

### To conclude
Studying CS is a journey, one tedious journey, but with practice you can learn to be better at CS. Happy coding!
